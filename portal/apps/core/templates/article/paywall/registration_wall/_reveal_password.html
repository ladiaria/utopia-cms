{% comment %} Reveal button for a password field, shared by the login and signup steps. `target` is the id of the input it toggles; registration_wall.js reads it and flips that input between type=password and type=text. The icon is the same pair the login page uses (img/icon-visibility_on.svg when the password is hidden, icon-visibility_off.svg when it is shown), painted as a background image from the scss, so the control looks the same wherever it appears. What is not shared is the handler: the site-wide .toggle-password of ld.js is bound to the nodes present at page load, and the wall replaces its own markup over ajax when it moves between steps, so the button would come back dead. The wall script delegates instead. {% endcomment %}
