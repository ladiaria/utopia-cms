{% comment %} Reveal button for a password field, shared by the login and signup steps. `target` is the id of the input it toggles; registration_wall.js reads it and flips that input between type=password and type=text. Not the site-wide .toggle-password of ld.js: that handler is bound to the nodes present at page load, and the wall replaces its own markup over ajax when it moves between steps, so the button would come back dead. The wall script delegates instead. The icon is also the one from the wall design (16x11) and not the 24x24 material one that .toggle-password paints as a background image. Both icons are in the markup and swapped with css, so the script carries no icon markup of its own. {% endcomment %}
